# Agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before implementation.

Planning is maintained in [baseharbor-plan](https://github.com/mcpdev80/baseharbor-plan). Before working, read its [AGENTS.md](https://github.com/mcpdev80/baseharbor-plan/blob/main/AGENTS.md) and your assigned task note at the current remote state.

- Follow the central ownership protocol before editing; preserve existing task ownership, branches and PRs.
- Update and push the assigned planning note when status, blockers, PR/source SHA or verification results change, and before handing off or stopping. Link actual evidence; keep acceptance with the Maintainer.
- Keep scope, dependencies and handoffs in that note. Migrated GitHub issues retain discussion/history and are not a second planning authority.

Product code, review and CI stay in this repository. Use its actual required checks; no runtime matrix is required solely for planning or instruction-file edits.
