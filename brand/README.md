# BaseHarbor brand

This demo consumes the canonical BaseHarbor CI v1.0 visual language from:

`mcpdev80/baseharbor/docs/brand`

The palette and typography tokens in this directory are copied from the canonical BaseHarbor source. Master artwork is not redrawn or re-typeset.

Canonical assets:
- BaseHarbor CI Guide v1.0
- master lockup
- mascot mark
- icons and favicon
- GitHub banner
