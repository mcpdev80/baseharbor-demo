Reference application

A normal Compose app. Portable infrastructure underneath.

This repository starts without BaseHarbor-specific files. BaseHarbor discovers the application, creates the contract and provides standard bindings. The app itself only speaks PostgreSQL, Redis, S3, HTTPS and OTLP.
