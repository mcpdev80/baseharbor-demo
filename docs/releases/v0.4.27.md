# BaseHarbor Demo v0.4.27

The guided deployment now confirms the exact application candidate before applying it. The companion application demonstrates independent app deployments and explicit cross-application connectivity.

The Demo remains a standard Compose application and uses BaseHarbor's portable application bindings. Its provider and runtime checks run through focused Docker and Podman acceptance gates.
