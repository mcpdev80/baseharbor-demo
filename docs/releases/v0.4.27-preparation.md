# BaseHarbor Demo and v0.4.27

The Demo is an ordinary application repository, without a prewritten BaseHarbor application contract or a dedicated SDK. Developers inspect a repository, adopt its supported workload and declare only the application capabilities they actually need. BaseHarbor resolves the associated services on the selected Target.

The Demo illustrates existing Compose workloads, managed SQL and portable application needs. The repository's pinned Core source is the integration reference; compatible release artifacts must use the corresponding versions.

See the [Demo quick start](../../README.md) and [BaseHarbor v0.4.27 release notes](https://github.com/mcpdev80/baseharbor/blob/develop/docs/releases/v0.4.27.md).
